# Formation Itiz

## Description

Ce projet nous permet d'apprendre les bases de `git` et de `tailwind`.

## Installation

Installer le projet - **première fois uniquement**

⚠️ [NodeJs](https://nodejs.org/en/download) doit être installé

- node v24+
- npm 10+

```
npm install
```

Pour lancer le compilateur :

```
npm start
```
